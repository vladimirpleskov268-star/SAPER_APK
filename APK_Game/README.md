# 💣 Minesweeper 2D Mobile & Desktop (Python)

Современная 2D игра «Сапёр» на Python, оптимизированная под сенсорные экраны телефонов и компьютеры. Поддерживает динамический выбор размера поля от **3х3 до 100х100+**, плавное масштабирование (зум), панорамирование (перемещение по полю) и готовую сборку в Android `.apk`.

---

## ✨ Особенности игры

- 📐 **Любые размеры поля (от 3x3 до 100x100+)**:
  - Готовые пресеты: **Easy (9x9)**, **Medium (16x16)**, **Hard (30x16)**, **Colossal (50x50)**.
  - Кастомный ввод строк, колонок и количества мин через меню.
- ⚡ **Viewport Culling (Оптимизация производительности)**:
  - На гигантских полях (100x100 = 10 000 ячеек) отрисовываются только ячейки, видимые на экране в данный момент. Это обеспечивает честные **60 FPS** даже на слабых смартфонах.
- 🛡️ **Безопасный первый клик**:
  - Первое нажатие гарантированно открывает пустую зону (без мин в стартовой ячейке и соседях).
- 📱 **Удобное мобильное управление**:
  - **Переключатель режимов (⛏️ DIG / 🚩 FLAG)** на нижней панели для комфортной игры одним пальцем.
  - Поддержка **Long-Press (долгого нажатия)** для быстрой установки флага.
  - **Панорамирование (Drag)**: свайп пальцем/мышью для перемещения по полю.
  - **Зум**: кнопки `+` / `-`, колесико мыши или жесты.
  - **Кнопка `🎯 Center`**: мгновенная подгонка размера всего поля под текущий экран.
- 🎨 **Современный Dark UI**:
  - Элегантная темная тема (Catppuccin Mocha), светодиодный дигитальный таймер, счётчик оставшихся мин, звуковые эффекты и анимации победы/поражения.

## 🚀 Быстрый запуск на ПК

1. Установите зависимости:
   ```bash
   pip install pygame-ce
   ```
2. Запустите игру:
   ```bash
   python main.py
   ```

---

## 📱 Сборка в Android APK

### Вариант 1: GitHub Actions (Автоматическая бесплатная сборка в облаке ☁️)
1. Загрузите файлы репозитория на GitHub.
2. Перейдите во вкладку **Actions**.
3. Выберите **Build Android APK** и нажмите **Run workflow**.
4. По завершении скачайте готовый файл `.apk` из раздела **Artifacts**.

### Вариант 2: Локальная сборка через Buildozer (Linux / WSL)
1. Установите buildozer:
   ```bash
   pip install buildozer cython
   ```
2. Запустите сборку APK:
   ```bash
   buildozer -v android debug
   ```
3. Итоговый APK будет сохранен в папке `bin/Minesweeper2D-1.0.0-debug.apk`.

## 🎮 Управление

| Действие | Команда на ПК | Сенсор на телефоне |
|---|---|---|
| Открыть ячейку | ЛКМ (в режиме DIG) | Тап (в режиме DIG) |
| Поставить флаг | ПКМ или кнопка FLAG | Тап (в режиме FLAG) или Долгое нажатие |
| Перемещение по полю | Перетаскивание мышью | Свайп пальцем |
| Масштаб (Zoom) | Колесо мыши / Кнопки `+` `-` | Кнопки `+` `-` |
| По центру | Пробел / Кнопка Center | Кнопка Center |
